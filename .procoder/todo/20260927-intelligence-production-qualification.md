# Intelligence production qualification after gap closure

Status: open
Created: 2026-09-27

## Description

Bounded follow-up disposition authorized by G10. Existing package capabilities
must be wired and independently qualified before broader completeness claims.
This task is intentionally not a release-blocking expansion of G02–G09.

## Acceptance criteria

- [ ] Produce a live semantic matrix for Go/TypeScript/Python SCIP and Go LSP,
      including immutable image/config revision, branch scope, supported edges,
      unsupported languages and failed/incomplete indexing behavior.
- [ ] Record a decision through the production knowledge API, start a later
      relevant agent run, and retain evidence of the decision and provenance in
      its assembled context; unrelated/cross-organization knowledge is absent.
- [ ] Wire production MCP HTTP operator credential references and isolated stdio
      sessions; prove per-call revocation, destination/organization binding,
      cancellation cleanup and no host process execution or credential logging.
- [ ] Publish a vendored dependency/operator-cache recipe and build a real
      dependency-using workspace with external network access demonstrably denied.
- [ ] Wire repository-selected model price lookup and demonstrate a real run
      stopping at an isolated cost budget; missing pricing and overflow refuse.
- [ ] Publish and test the vulnerability lockfile/ecosystem matrix and offline
      advisory refresh procedure; corrupt, absent and expired snapshots fail closed.

## Scope decisions

Agent/service pushes have no implicit human CI sponsor. Any delegated sponsorship
feature needs a separately approved identity/revocation design. Existing member
default-branch push rights remain; they confer no deployment credential or approval.
